## 第五周核心发现

通过 ER 模型反推 v0.1 设计，发现 3 项拟在第六周调整的问题：

1. **订单必须至少有一条明细**：业务规则，数据库未强制 → 拟加触发器
2. **每个商品必须有库存记录**：业务规则，数据库未强制 → 拟加触发器
3. **库存变更无历史记录**：仅存最后更新人 → 拟新增 inventory_log 表

详见 `week5/v0.1问题清单.md`。
