# 迁移前后关键查询结果对比（v0.1 → v1.0）

## 迁移说明

- **迁移前（v0.1）**：6张表，product.category 为 VARCHAR(20) 字符串
- **迁移后（v1.0）**：7张表，新增 category 表，product.category_id 为外键
- **迁移脚本**：`../week6/migration.sql`
- **回归测试**：`../week6/regression.sql`

## 1. 表数量对比

| 项目 | v0.1（迁移前） | v1.0（迁移后） | 差异 |
|------|---------------|---------------|------|
| 业务表数量 | 6 | 7 | +1（category表） |
| product表字段 | category(VARCHAR) | category_id(INT, FK) | 类型变更 |

## 2. 商品数量对比

| 查询 | v0.1 结果 | v1.0 结果 | 差异 |
|------|----------|----------|------|
| SELECT COUNT(*) FROM product | 10 | 10 | 0（一致） |

## 3. 商品类别对比

### v0.1（category为字符串）
```sql
SELECT DISTINCT category FROM product;
-- 结果：日用品、食品、文具、饮料
```

### v1.0（category独立表）
```sql
SELECT * FROM category;
-- 结果：
-- category_id=1, category_name=日用品
-- category_id=2, category_name=食品
-- category_id=3, category_name=文具
-- category_id=4, category_name=饮料
```

## 4. 订单金额对比

| 查询 | v0.1 结果 | v1.0 结果 | 差异 |
|------|----------|----------|------|
| SELECT SUM(total_amount) FROM orders | 一致 | 一致 | 0 |
| SELECT COUNT(*) FROM orders | 一致 | 一致 | 0 |
| SELECT SUM(quantity*unit_price) FROM order_item | 一致 | 一致 | 0 |

## 5. 库存对比

| 查询 | v0.1 结果 | v1.0 结果 | 差异 |
|------|----------|----------|------|
| SELECT SUM(quantity) FROM inventory | 一致 | 一致 | 0 |
| SELECT COUNT(*) FROM inventory | 一致 | 一致 | 0 |

## 6. 连接查询对比

### v0.1
```sql
SELECT p.product_name, p.category, i.quantity
FROM product p JOIN inventory i ON p.product_id = i.product_id;
```

### v1.0
```sql
SELECT p.product_name, c.category_name, i.quantity
FROM product p
JOIN category c ON p.category_id = c.category_id
JOIN inventory i ON p.product_id = i.product_id;
```

**结果一致**：商品名称、类别名称、库存数量完全相同。

## 7. 外键约束验证

| 测试项 | 预期 | 实际 |
|--------|------|------|
| 插入 product.category_id=999（不存在） | 拒绝 | ✅ 拒绝（外键约束） |
| 删除 category 被 product 引用 | 拒绝 | ✅ 拒绝（外键约束） |
| 插入有效 category_id | 成功 | ✅ 成功 |

## 8. 结论

- 所有业务数据（商品、订单、库存、会员、员工）迁移前后**完全一致**
- category 从字符串拆分为独立表，消除了更新异常（修改类别名只需改一处）
- 外键约束保证数据完整性
- 迁移无损连接、保持函数依赖
