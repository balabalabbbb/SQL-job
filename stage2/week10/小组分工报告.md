## 协作方式

1. **Git 协作**：通过 GitHub 仓库管理，功能开发后由组长审查合并。
2. **任务分配**：本周开始前明确数据库对象、应用改造、测试文档三条线的负责人和交付物。
3. **代码审查**：组长负责 SQL 与 Java 代码审查，确保接口、错误号、权限配置规范。
4. **问题沟通**：遇到接口、前端、数据问题及时讨论，共同定位根因后再修改。
5. **文档共享**：所有脚本与文档存放于仓库，数据口径统一，便于复现和核对。
