# 小卖部管理系统 Web 应用（第7-9周）

## 项目概述

基于 Flask 框架的四层架构 Web 应用，将前6周设计的 SQL Server 数据库应用到实际程序中，实现小卖部的日常经营管理。

## 技术栈

- **Web 框架**: Flask 3.x
- **数据库**: SQL Server 2019
- **数据库驱动**: pyodbc 5.x
- **密码加密**: bcrypt
- **前端**: Jinja2 模板 + 原生 HTML/CSS

## 四层架构

```
页面层 (routes/)    → 路由、请求处理、会话管理
业务层 (services/)  → 业务规则、事务、权限校验
数据访问层 (dal/)   → 参数化SQL、连接管理、事务
数据库层 (SQL Server) → 7张表、约束、视图、角色
```

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 配置数据库连接（编辑 config.py）

# 启动应用
python app.py
```

访问 http://127.0.0.1:5000

## 核心功能

1. **登录认证**：员工账号密码登录（bcrypt加密）、会员手机号登录
2. **商品管理**：商品CRUD，仅员工可操作
3. **库存管理**：库存查询、调整、低库存预警
4. **订单管理**：创建订单在单个事务中完成（校验→写订单→写明细→扣库存→更新积分）
5. **角色权限**：未登录401、越权403、库存不足409
6. **统一异常**：8类业务异常，统一错误响应
7. **日志记录**：请求日志、错误日志
