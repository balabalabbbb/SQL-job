## 三、协作与验证机制

1. 每位成员完成本人负责的对象后，先在本地 SQL Server 真实运行并保存证据，再提交组内评审。
2. 成员之间交叉评审代码与结果，重点检查异常处理、事务边界和数据一致性，发现问题退回修改。
3. 全部对象完成后，由组长统一从 `00_init` 基线完整复现 exp1—exp5 并执行 `99_cleanup`，确认可重复运行、结束 `@@TRANCOUNT=0`。
4. AI 辅助情况及人工修改、验证结论统一记录在 `ai_log.md`。
